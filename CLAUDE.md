## The project in three lines

Forme NURBS is a hard-surface modelling app (PC first, iPad later): an object is a list of features (Cube, Cylinder…) combined in order (Add = union, Carve = cut), built as exact B-rep solids by **OpenCascade** and shown as its mesh with its B-rep edges. The UI looks like Forme's « Établi » interface (floating islands, tool cards, one inspector, history strip), in English, dark, with the white accent.

## Code map

- `crates/forme-occt`: our thin C layer over OpenCascade (`cpp/forme_occt.cpp` + safe Rust wrapper). Primitives, transforms, booleans, fillets / chamfers by edge index, meshing. Every OpenCascade exception is caught and returned as `Err`; only `opencascade::handle<T>` is used (the `Handle_T` aliases break under MSVC). **Face tags**: each face carries an `i64` tag that booleans, transforms, fillets and chamfers carry to the faces they make (`carry_tags`, history `Modified`); new fillet / chamfer faces get the `fresh` tag. `Shape::topo(defl, angle)` returns in one buffer the faces (tag, surface kind, plane point / normal, axis, radius), the mesh with a face index per triangle, and the edges (index, the two faces, kind, seam, polyline). OpenCascade is built by `occt-sys` (feature `builtin`, cached in `target/OCCT`) or taken from `FORME_OCCT_ROOT`.
  Quads: `quad_topo()` (each face's wires in order, each edge's ends, kind and samples), `edge_on_face(face, edge, reversed, t)` (points and the face's uv along an edge), `face_eval(face, uv)` (points and outward normals).
  Faces: `inset_face(face, d)` (BRepOffsetAPI_MakeOffset, needs TKOffset; the wires are rebuilt from fresh edges on their 3D curves, else the booleans fail on a face with holes; d = 0 copies the face), `extrude(v)`, `imprint(tool)` (Splitter: the face under the tool cut along its outline, the inside takes the tool's tag), `face_distance(face, p)`. In a boolean, a face made of faces of both shapes (flush faces merged) keeps the part's tag, not the tool's.
- `crates/nurbs-kernel`: the document and the kernel.
  - `doc.rs`: `Doc { features }`, `Feature { id, name, op, prim, origin, rot, visible, material, round }`. A feature's origin is the centre of its base; it rises along its local +Y. Saved as JSON `.fnurbs`. A feature with `round: Some(Round { size, chamfer, edges })` is a fillet / chamfer step on what is built before it (`is_solid()` is false; its `op`, `prim`, `rot` are unused). Each edge is an `EdgeRef { faces: [tag, tag], at }`: the packed tags of the two faces it joins, and its middle point to choose between edges joining the same two faces (`build::resolve`). The fillet's new faces carry the tag `(fillet id, 0)`, so clicking them selects the fillet. A feature with `push: Some(Push { face: FaceRef { tag, at }, inset, depth })` is an Inset / Extrude step (label "Inset" when inset > 0, else "Extrude"; `Doc::add_push`). A sketch is `Prim::Profile { x, y, z }` (its outline's box, its height) with `profile: Some(Profile { points, smooth })`, the points in the unit square of local X / Z (resizing stretches it); a curve point is a quadratic curve between the middles of its two sides (`doc::pieces`, same as `focc_prism`).
  - `model.rs`: what the kernel sends back: mesh, `tri_face`, faces with their `FaceTag { feature, sub }` (box sub: 0 +X, 1 −X, 2 top, 3 bottom, 4 +Z, 5 −Z; cylinder: 0 side, 1 top, 2 bottom), edges, errors; binary encode / decode.
  - `build.rs` (feature `occ`): features applied in order (a Carve with nothing before it is ignored), tool solids cached by feature hash, stages by prefix hash, a sketch's faces tagged 1 top, 2 bottom, 3 + its outline piece id (`sub_of`), `STEP what:id:hash` written on stderr before each risky step. `push`: the face found by tag and nearest point (`find_face`), inset, then imprinted (depth 0), fused or cut as a prism (carving starts 0.1 mm outside the face); its new faces tagged `(step, 1)` for the inset or the end, `(step, 2…)` for the sides.
  - `quads.rs` (feature `occ`): the quad converter. `convert(shape, target)`: each face's loops in a (u, v) map scaled to millimetres (`FMap`, the outline counter-clockwise; for a closed edge the pcurve that keeps the loop going is taken, `Span.pc`), cut into regions with four corners (outline turns > 25°) by straight cuts that stop at the first line they meet (a T), on a node when one is close. In order: several holes kept apart by a cut across the face (`separate`); each hole joined by a left and a right ray; then per region a ray along a side of an inner corner, a ray from an inward arc of more than 120° (where it runs along u or v), a ray straight in where a straight side meets a rounded one, the best chord while more than 4 corners (`score`: corner counts, angles, no sliver, no cut brushing past the outline, `clear`), a disc (a round loop with no corner) cut into a centre square and four side patches by paths through new inner points (`disc`, `split_path`), forced corners while fewer (where a straight side meets a rounded one, else the middle of the longest run). The lines (B-rep edges and cuts) are split into pieces at their nodes; segment counts by length (arcs at least one per 22.5°), raised until opposite sides match; points shared by node / piece, a Coons grid in uv evaluated on the surface, quads turned outwards. `QuadMesh::is_closed`, `bad_quads`, `obj`; `FORME_QUADS_DEBUG=1` prints the cuts. Asked with `Request.quads` (fine builds only); sent back as `Model.quads` (`Quads { positions, quads, quad_face, skipped }`, appended at the end of the encoding).
  - `client.rs`: the app side. The kernel runs in its own process `forme-nurbs-kernel` (u32-length frames on stdin / stdout, JSON request, binary model): a hard crash inside OpenCascade cannot take the app down; the client restarts it with the failing step skipped and the model lists what was left out. The latest request wins; coarse meshing while a gesture is live, fine after.
- `crates/nurbs-app`: the app.
  - `render.rs`: wgpu, MSAA 4×: background (gradient, ground grid 10 / 50 mm, origin axes), the part's mesh with per-face flags (selected / hovered) in a storage buffer, B-rep edges as anti-aliased screen-width lines, overlay outlines (cutters, shapes being moved or created) with a dimmed hidden part.
  - `pick.rs`: ray against the kernel's triangles, face by face → the face's tag → the feature. No SDF, no approximation.
  - `state.rs`: `AppState` (document, undo / redo with live edits, selection, tools, 3ds Max-like creation on the ground or a flat face, move gizmo and size handles, kernel round trips). Features go here first. `SelMode::{Vertex, Edge, Face, Object}` (1 to 4, Q = Object, the mode pill in the top island): in Edge mode `pick_edge` finds the nearest visible model edge on screen, `edge_sel` holds the picked `EdgeRef`s, `set_round` makes the fillet at the first size (or sets the selected one's), Shift + click on an edge adds it to the selected fillet. `Sketch` (with `Tool::Create(PrimKind::Profile)`): `sketch_press` / `sketch_drag` / `sketch_close`, then the same height phase as the other shapes (`Creation::profile`, mirrored when it grows down).
  - `faces.rs`: Face and Vertex modes (`face_sel: Vec<FaceRef>`, `model_face_of`, `click_face`, `vertices` = the ends of the edges, `pick_vertex`), `make_inset` (2 mm at once), the Extrude gesture (`Tool::Push(PushKind)`, `PushGesture`: `arm_push`, `push_press`, `push_move`, `push_next`, `finish_push`; depth along the normal from where it began), the selected step's handles (`push_handles`, `Handle::PushInset` / `PushDepth`, dragged on a stored line by `begin_push_drag` / `update_push_drag`), `set_push` from the panel.
  - `viewport.rs`: gestures (Maya navigation: Alt + left orbit, Alt + middle pan, Alt + right zoom, wheel zoom), gizmo, creation and marquee drawing, kernel status line.
  - Quads view: `AppState.quads` (the request serial is `version * 4 + fine * 2 + quads`), `quad_mesh()`, `export_obj()` (Documents/Forme NURBS/<name>.obj, one group per face); `draw.rs` uploads the quads (smooth normals inside a face), their wire, the skipped faces' triangles, and colours fillet faces `BAND` orange.
  - `ui.rs` + `widgets.rs` + `theme.rs` + `icons.rs`: the Établi-style islands, inspector, history strip, files dialog; `draw.rs`: what is uploaded to the renderer each frame; `materials.rs`: the 6 materials (colour, metal, roughness) read per face by the shader; `files.rs`, `settings.rs`: `~/Documents/Forme NURBS`.
  - `bin/shot.rs`: the capture harness (`test_part()`: Block, Hole, Boss, Slot).

## Rules that are easy to break

- **No SDF, ever, on this branch**: the part on screen is always the kernel's mesh. While the kernel computes, the previous mesh stays, with the moved or created shape drawn as an outline.
- Picking and selection go through the kernel's faces and their tags (`Model::faces[f].tag`), never through a field or a guess from the shape list.
- A tag is `(feature << 16) | sub`; any new primitive must tag all its faces in `nurbs_kernel::build::sub_of`. Edges are never named by their index in OpenCascade's edge map (it changes with every build): always by the tags of their two faces.
- Both sides of the kernel protocol (`proto.rs`, `model.rs` encode / decode) change together; the kernel process is rebuilt with the app.
- Never commit `target/` or `shots/replay/frames/`. Never run `cargo fmt` on the whole tree.
